Annual Report Q&A

Project Url = https://annual-report-q-a-a9zmmt4j7nhakbwvx8qhuj.streamlit.app/

The webapp lets you upload a company's annual report (PDF) and ask questions in a chat box. It finds the most relevant passages with TF-IDF retrieval, then uses a Groq-hosted LLM to answer with page references. Built with Python, Streamlit, and scikit-learn, and deployed on Streamlit Community Cloud. For education only, not financial advice.
